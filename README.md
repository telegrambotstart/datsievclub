# Datsiev Club landing

Первая версия лендинга на 3 блока:

1. Презентационный экран с названием клуба, слоганом, видеофоном, фактами и CTA.
2. Интерактивный блок направлений клуба.
3. Блок стоимости абонементов.

## Как посмотреть локально

Откройте файл `index.html` в браузере. Сборка и установка зависимостей не нужны.

## Как выложить на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите в него все файлы из этой папки: `index.html`, `styles.css`, `script.js`, `README.md`, папку `assets`.
3. Откройте в репозитории `Settings` -> `Pages`.
4. В `Build and deployment` выберите `Deploy from a branch`.
5. В `Branch` выберите `main` и папку `/root`.
6. Нажмите `Save`.
7. Через 1-2 минуты GitHub покажет ссылку на сайт.

## Видео на первом экране

Сейчас hero-блок подготовлен под локальное MP4-видео и использует картинку-постер `assets/hero/poster.png`.

Чтобы поставить свое видео:

1. Добавьте файл `training-hero.mp4` в папку `assets/hero`.
2. Оставьте имя файла именно `training-hero.mp4`.
3. Обновите страницу.

YouTube-встраивание убрано, потому что при локальном открытии сайта оно может показывать ошибку 153 вместо фонового видео.

## Если видео тормозит

Для фонового видео важен не только размер файла, но и кодек, разрешение, FPS и длительность. Оптимальные параметры:

- формат: MP4;
- кодек: H.264;
- длительность: 8-15 секунд;
- разрешение: 960x540 или 1280x720;
- FPS: 24 или 30;
- звук: удалить;
- размер: желательно 1-4 МБ.

Если используете HandBrake:

1. Откройте видео в HandBrake.
2. Preset: `Fast 720p30` или `Fast 540p30`.
3. Format: `MP4`.
4. Video Encoder: `H.264`.
5. Framerate: `30` или `24`, `Constant Framerate`.
6. Audio: удалить дорожку.
7. Сохраните файл как `training-hero.mp4` и замените файл в `assets/hero`.

Если используете FFmpeg:

```bash
ffmpeg -i input.mp4 -t 12 -vf "scale=1280:-2,fps=30" -an -c:v libx264 -preset veryfast -crf 28 -movflags +faststart training-hero.mp4
```
